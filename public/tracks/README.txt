ASTRAL RESONANCE — TRACKS FOLDER
================================

Drop your .mp3 (or .ogg / .wav) files into this folder.
They appear on the track-select screen — click RESCAN after adding
files while the dev server is running.

Files in this folder are personal media and are gitignored;
they never get committed.

Note: playing a track decodes it fully into memory
(~23 MB per minute of stereo audio), so very long mixes
will use a lot of RAM.
